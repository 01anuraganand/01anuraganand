### 👨‍💻 About Me

Hey there! I'm **Anurag Anand**, an engineer and founder based in India. I run **[NextAISense Tech](https://nextaisense.com/)**, where our team develops intelligent robotics systems, cloud-based simulation engines, and enterprise software platforms.

My day-to-day engineering spans:
- 🤖 **Embodied AI & Robotics:** Building dual-arm humanoid manipulators, motion planning pipelines in **MoveIt 2**, kinematic models with **URDF/Xacro**, and real-time physical simulation in **ROS 2 & Gazebo**.
- ☁️ **Cloud Robotics Simulation:** Architecting **Galaxium**, a web-based simulation platform integrating ROS 2 with Gazebo, MuJoCo, and cloud compute to remove local hardware bottlenecks.
- 🏛️ **Enterprise Multi-Tenancy (TBMS):** Architecting production platforms with PostgreSQL schema isolation (`django-tenants`), Casbin ABAC/RBAC, and healthcare interoperability standards (FHIR, HL7, DICOM).
- 🎨 **Creative 3D Web & Interactive Systems:** Building high-fidelity 3D web applications, physics simulations, and responsive frontends with **Next.js, Three.js, React Three Fiber**, and **Tailwind CSS**.
- 🧠 **Autonomous AI & LLM Systems:** Orchestrating production agentic pipelines with **LangChain**, **Guardrails AI**, and **LlamaIndex**, leveraging **Claude**, **Google Gemini**, **Perplexity AI**, and **OpenAI** for multi-model reasoning and verified automated workflows.
